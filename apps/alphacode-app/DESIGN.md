# AlphaCode App 设计约定

界面的唯一来源是 `apps/alphacode-web`，包括主题变量、组件、翻译和行为测试；当前视觉规范见 [Web DESIGN.md](../alphacode-web/DESIGN.md)。Electron 加载同一构建，不复制或改写组件，浏览器与桌面保持一致。

工作区使用冷银浅色／石墨深色、局部磨砂导航和实色内容。桌面侧栏总宽 264px（内表面 248px），收起为 72px（图标轨 56px）；外壳间距 8px、圆角 14px，顶栏 44px，输入区最大 680px。小于 768px 复用 Web 的 288px 抽屉和 52px 顶栏。

原生外壳提供系统标题栏、窗口生命周期、编辑菜单、文件选择、外链处理和后端连接。默认窗口 1200 × 820，最小 680 × 520；主题与语言使用已有 Web 控件，不新增独立设置或导航。

所有面向用户的标题、菜单和发行名称使用 **AlphaCode**；`alphacode-app` 只标识源码包与内部运行时。
