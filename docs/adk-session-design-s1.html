01 / DECISION

独立能力包，以 Session 作为统一术语

Session 是跨多次运行的持久会话；Run 是一次 core.prompt。Thread 在本方案中只是“会话”的同义词，不再增加 ThreadManager、ThreadStore 或第二套 ID。

方案对 core 的影响保存语义判断
直接内置到 core引入存储、会话索引和恢复职责可以控制，但依赖面扩大与微内核定位不匹配
只做 core Plugin需新增加载、状态读取和受控保存 hook现有 observe 不被等待，也没有完整快照当前接口不足以单独承担
独立 Session 包组合 Agent使用 prompt / state / replaceMessages / closeSession 等待 core 完成，再等待存储提交推荐首版
可插拔体现为显式组合。业务可以选择是否使用 Session，替换 SessionStore 和上下文选择策略。Session 拥有 Agent 的使用权，但不重写 Loop；首版不提供一个功能重复的 createSessionPlugin()。

包布局

packages/adk/           → @alpha/adk/core
packages/adk-session/   → @alpha/adk-session
  src/index.ts         # 管理器、契约、内存适配器
  src/sqlite/          # 可选 SQLite 子入口

@alpha/adk-session/sqlite
  → createSqliteSessionStore(...)

依赖原则

  • Session 只引用 core 公开类型；通过注入的 Agent 工厂获取实例。
  • core 不感知 sessionId、数据库、目录或存储适配器。
  • SQLite 驱动只从 sqlite 子入口加载；具体驱动在实施前按 Node 版本验证。
  • 首版采用一个新增包；未来重型数据库驱动可再拆独立适配器包。

归档是完整记录，上下文是本次选择

Session稳定 ID + agentKey + 元数据namespace 内唯一
1 → N
SessionTurn一轮已收束的 core 运行RunResult + 本轮新增 Message[]
0 → N
Message直接复用 core 只读消息保留配对与 continuation
标识 / 对象归属与语义生命周期

revision存储版本；准入与最终提交各做一次 CAS单调递增；不同于消息 seq
pending执行前持久化的受理标记，含 requestId、输入摘要、唯一 token结果与消息原子保存后移除
agentKey应用维护的兼容性版本，覆盖模型 / 协议、指令与工具配置不匹配时拒绝运行，不能静默复用 opaque continuation
ARCHIVE

SessionStore 持有完整会话

每轮只向逻辑归档追加该轮新增的正式消息。保存 core 原始终态和 historyStatus；不保存预览 delta、函数、客户端或 appContext。

出现 outcome_unknown 时，整段会话标为 blocked。省略旧轮次不能绕过这个判断。

WORKING CONTEXT

Agent 持有运行工作集

selectContext 返回按原顺序排列的完整 runId 子集。Session 将其消息交给 replaceMessages() 校验，再执行下一轮。

默认选全部，超出 core 容量就拒绝；示例显式选择最近 12 轮。归档保留原文，首版不自动摘要。

运行前记录导入基线；运行结束后检查基线前缀未改变，仅保存其后新增消息。工具批次作为完整轮次的一部分保留，禁止把 toolResult 单独裁掉。单轮自身的容量限制仍由 core 执行。

// Implemented S1 API. Runnable offline examples: packages/adk-session/examples/conversation.js.
import { createAgent } from '@alpha/adk/core';
import { createSessionManager } from '@alpha/adk-session';
import { createSqliteSessionStore } from '@alpha/adk-session/sqlite';
import type { LanguageModel } from '@alpha/provider';

// The application supplies its existing provider.use(...) model and authenticated scope.
export async function example(model: LanguageModel, namespace: string) {
  const store = await createSqliteSessionStore({ filename: './sessions.db' });
  const sessions = createSessionManager({
    namespace,
    agentKey: 'support-agent@1',
    store,
    createAgent: ({ signal }) => createAgent({
      model,
      instructions: '根据已有对话回答，明确区分事实与推测。',
      signal,
    }),
    // This selects context; the full archive remains available in the store.
    selectContext: ({ turns }) => turns.slice(-12).map(turn => turn.run.runId),
  });
  try {
    const session = await sessions.createSession({ title: '产品咨询' });
    const unsubscribe = session.subscribe(event => {
      if (event.type === 'agent' && event.event.type === 'model.delta') {
        console.log(event.event.text);
      }
    });
    try {
      const result = await session.prompt('请记住我的预算是 500 元。', {
        requestId: 'request-001',
      });
      console.log(result.run.status, result.persistence.status);
      if (result.persistence.status === 'pending') {
        const saved = await session.flush();
        if (saved.status === 'pending') throw new Error(saved.code);
      }
    } finally {
      unsubscribe();
      await session.close();
    }
    // Reopen after close; after a process restart, rebuild store/manager with the same
    // namespace and agentKey, then open the saved session ID in exactly this way.
    const resumed = await sessions.openSession(session.id);
    const result = await resumed.prompt('我的预算是多少？', { requestId: 'request-002' });
    if (result.persistence.status === 'pending') {
      const saved = await resumed.flush();
      if (saved.status === 'pending') throw new Error(saved.code);
    }
    console.log(result.run.text);
  } finally {
    try { await sessions.close(); }
    finally { await store.close(); }
  }
}

/**
 * ADK Session S1 — implemented API, 2026-11-04.
 * Normative semantics: docs/adk-session-s1-spec.md.
 * Source: packages/adk-session/src/contracts.ts and package exports.
 * The session package composes the existing public core API; core is unchanged.
 */
declare module '@alpha/adk-session' {
  import type { AdkError, Agent, AgentEvent, Awaitable, DeepReadonly, JsonObject, Message, RunResult } from '@alpha/adk/core';

  export interface SessionKey { readonly namespace: string; readonly id: string }
  export interface SessionTurn {
    readonly requestId: string;
    readonly inputHash: string;
    readonly run: DeepReadonly<RunResult>;
    /** Only messages appended by this run, including finalized tool outcomes. */
    readonly messages: readonly Message[];
    readonly historyStatus: 'ready' | 'blocked';
    readonly committedAt: string;
    /** Revision of this turn's atomic commit; reused in idempotent receipts. */
    readonly committedRevision: number;
  }
  export interface PendingRequest {
    readonly requestId: string;
    readonly inputHash: string;
    /** Unique admission token; never reused or automatically taken over. */
    readonly token: string;
    readonly startedAt: string;
  }
  export interface SessionData {
    readonly formatVersion: 1;
    readonly id: string;
    /** Application-managed compatibility identity for model, tools and instructions. */
    readonly agentKey: string;
    readonly title: string;
    readonly metadata: JsonObject;
    readonly createdAt: string;
    readonly updatedAt: string;
    readonly turns: readonly SessionTurn[];
    readonly pending: PendingRequest | null;
  }
  export interface SessionSnapshot {
    readonly revision: number;
    readonly data: SessionData;
  }
  export interface SessionSummary {
    readonly id: string;
    readonly revision: number;
    readonly title: string;
    readonly updatedAt: string;
    readonly status: 'ready' | 'pending' | 'blocked';
  }
  export interface Page<T> { readonly items: readonly T[]; readonly cursor?: string }
  export interface ListOptions { readonly cursor?: string; readonly limit?: number }
  export interface SessionError extends Error {
    readonly code: string;
    /** Present when a create acknowledgement was lost and the ID needs inspection. */
    readonly sessionId?: string;
    readonly cleanupErrors?: readonly Readonly<AdkError>[];
  }
  export interface SessionLimits {
    readonly maxTurns: number; // default 1000; admission limit
    /** default 64 MiB; admission threshold, not a reason to discard a finalized turn */
    readonly maxArchiveBytes: number;
  }
  export type CasResult =
    | { readonly applied: true; readonly revision: number }
    | { readonly applied: false };

  /** Adapter-author API. Every operation is scoped; CAS MUST be atomic. */
  export interface SessionStore {
    /** memory is intentionally volatile; transactional promises survive process restart. */
    readonly durability: 'memory' | 'transactional';
    create(key: SessionKey, data: SessionData): Promise<SessionSnapshot>;
    read(key: SessionKey): Promise<SessionSnapshot | undefined>;
    list(namespace: string, options?: ListOptions): Promise<Page<SessionSummary>>;
    /** next=null tombstones the ID. Applied writes increment revision; IDs cannot be reused. */
    compareAndSet(key: SessionKey, expectedRevision: number, next: SessionData | null): Promise<CasResult>;
    close(): Promise<void>;
  }

  export type SaveResult =
    | { readonly status: 'saved'; readonly revision: number }
    | { readonly status: 'pending'; readonly code: 'STORE_UNAVAILABLE' | 'COMMIT_CONFLICT' };
  export interface SessionResult {
    readonly requestId: string;
    /** Unchanged core outcome; storage failure must not rewrite execution facts. */
    readonly run: DeepReadonly<RunResult>;
    readonly persistence: SaveResult;
  }
  export type SessionEvent =
    | { readonly type: 'agent'; readonly sessionId: string; readonly event: AgentEvent }
    | { readonly type: 'session.saved'; readonly sessionId: string; readonly requestId: string; readonly revision: number }
    | { readonly type: 'session.unsaved'; readonly sessionId: string; readonly requestId: string; readonly code: 'STORE_UNAVAILABLE' | 'COMMIT_CONFLICT' };
  export interface SessionState {
    readonly status: 'idle' | 'running' | 'saving' | 'unsaved' | 'closed';
    /** Eligibility follows the stored archive, even when context omits old turns. */
    readonly historyStatus: 'ready' | 'pending' | 'blocked';
    readonly revision: number;
  }
  export interface Session {
    readonly id: string;
    readonly state: SessionState;
    /** requestId must remain stable for retries of the same logical input. */
    prompt(input: string, options: { readonly requestId: string; readonly signal?: AbortSignal }): Promise<SessionResult>;
    subscribe(listener: (event: SessionEvent) => void): () => void;
    abort(reason?: string): void;
    /** Retry only the captured storage commit. Unknown persisted pending rejects. */
    flush(): Promise<SaveResult>;
    /** Abort/drain core, flush once, then close its Agent. May reject if unsaved. */
    close(): Promise<void>;
  }
  export interface SessionManagerOptions<C = undefined> {
    readonly namespace: string;
    readonly agentKey: string;
    readonly store: SessionStore;
    readonly limits?: Partial<SessionLimits>;
    /** Observer errors do not affect execution or saving; no raw error payloads. */
    readonly onObserverError?: (error: Readonly<AdkError>) => void;
    /** Return a fresh, idle Agent with empty history; ownership transfers to Session. */
    readonly createAgent: (context: { readonly sessionId: string; readonly signal?: AbortSignal }) => Promise<Agent<C>>;
    /** Select complete turns, in original order. Default selects all turns. */
    readonly selectContext?: (context: {
      readonly turns: readonly SessionTurn[];
      readonly signal?: AbortSignal;
    }) => Awaitable<readonly string[]>; // selected core runIds
  }
  export interface SessionManager {
    createSession(input?: { readonly id?: string; readonly title?: string; readonly metadata?: JsonObject }): Promise<Session>;
    openSession(id: string): Promise<Session>;
    getSession(id: string): Promise<SessionSnapshot | undefined>;
    listSessions(options?: ListOptions): Promise<Page<SessionSummary>>;
    updateSession(id: string, patch: { readonly title?: string; readonly metadata?: JsonObject }, options: { readonly expectedRevision: number }): Promise<SessionSnapshot>;
    deleteSession(id: string, options: { readonly expectedRevision: number }): Promise<void>;
    /** Closes owned Session handles; the borrowed store remains application-owned. */
    close(): Promise<void>;
  }
  export function createSessionManager<C = undefined>(options: SessionManagerOptions<C>): SessionManager;
  export function createMemorySessionStore(): SessionStore;
}

declare module '@alpha/adk-session/sqlite' {
  import type { SessionStore } from '@alpha/adk-session';
  /** Optional Node adapter. No SQLite driver is imported by the package root. */
  export function createSqliteSessionStore(options: { readonly filename: string }): Promise<SessionStore>;
}

接口确定约定
createSessionManager同步组合配置，不发起 I/O。绑定 namespace / agentKey；store 由应用持有。
createSession / openSession异步创建 / 读取会话句柄；不是恢复未完成的执行栈。Agent 可延迟到 prompt 前创建。

session.flush仅处理本句柄捕获的待保存结果；没有待保存内容且持久记录 ready 时返回当前确认 revision；记录仍有未知 pending 时拒绝。
session.subscribe转发 core 事件并包装 sessionId；core run.end 只表示执行结束，session.saved 才表示存储确认。
session.close / manager.close幂等；取消并等待运行，尝试 flush，再释放所有自有 Agent。即使保存失败也释放资源，并报告失败。

07 / GUARANTEES & LIMITS

恢复到已保存轮次，保守处理未知执行

首版承诺：正常保存的会话可在重启后继续。首版没有执行栈、模型流或工具调用级 checkpoint；进程在运行中终止时，保留“已受理、结果未确认”的标记并阻止自动重放。
边界场景规定行为
读取 / 构建 Agent / 投影失败在准入前 reject，零模型与工具调用；清理新建但未使用的 Agent。
pending 写入成功但确认丢失原进程可读取并核对自己生成的 token，且必须能证明尚未调用 core。不能确认则停止；新进程看到 pending 一律要求人工核对。
同 requestId、同输入重试已提交：直接返回原 RunResult 与原提交 receipt，不发新 core 事件。进行中或结果未知：拒绝执行。输入不同：REQUEST_MISMATCH。
多个进程打开同一 Session每次运行前刷新记录；原子准入只允许一个获胜。失败者不调用 core。S1 不使用 TTL 自动接管，不靠最终保存 CAS 来防止重复副作用。
core 完成，保存失败保持原 RunResult；句柄变 unsaved，保留内存中的完整提交数据。flush 使用同一 token 重试提交；严禁重跑 prompt。
最终提交成功但确认丢失重新读取已保存的 requestId、inputHash 与内容摘要；匹配则确认 saved，不能重复追加。已提交 receipt 需要由存储保留。
进程中断后重新打开pending 可供读取与检查，但 prompt 返回 RECOVERY_REQUIRED。不能把上一轮当作“没发生”；人工核对 / 修复 API 留到 S2 独立设计。
core 返回 blocked照实保存完整消息与状态；后续运行拒绝恢复。当前 replaceMessages 不接受 outcome_unknown，因此不能伪装为 ready 导入。
signal 中止 / close只取消执行，不跳过收束后保存；存储不能复用已 aborted 的运行 signal。close 会等待必要 I/O，S1 不承诺强制终止或固定时限。
模型或配置发生变化agentKey 不符时 AGENT_MISMATCH；应用负责版本准确性。Session 不推测 continuation 是否能跨模型迁移。
存储契约必须落实的细节
  • 所有操作携带 namespace；由服务端可信身份构造。namespace 是隔离地址，不替代鉴权。
  • create 唯一插入；初始 revision 为 0；CAS 成功推进一个版本，失败不修改任何字段。
  • Session 服务禁止 pending 存在时重命名、改元数据或删除；CAS 再次阻止检查与写入之间的竞态。元数据不发送给模型。
  • 输入摘要使用规范化的输入与 agentKey；信号和网络传输细节不进入幂等判定。存储还须保留每轮确认 revision，供重复请求返回相同 receipt。
  • 单条数据使用格式版本；未知版本或坏数据返回 SESSION_FORMAT_INVALID，禁止当作空会话。首版只写 v1，不做隐式迁移。
  • Memory 的 saved 仅表示写入内存；SQLite 的 saved 以数据库事务提交为准，验收覆盖进程重启，不额外承诺所有硬件断电场景。
  • SQLite 子入口要求多进程原子 CAS；实现必须验证事务、busy timeout、唯一键和回滚行为。JSONL 暂缓：纯 appendFile 不能满足本稿的原子准入契约。
  • 新运行默认受 1000 轮 / 64 MiB 归档准入阈值约束。已受理轮次即使跨过归档阈值也要完整保存；存储物理容量不足时保留 unsaved，不丢掉已确认工具结果。

S1 可以做到

  • 隔离与列出会话，修改元数据，显式删除。
  • 恢复已保存的对话，等待最终持久化。
  • 阻止同会话并发受理，识别重复请求。
  • 完整归档与有限运行上下文分离。

独立后续能力

  • 运行中断点续执行、审批暂停恢复。
  • 外部副作用跨进程 exactly-once。
  • TTL 锁接管、分布式任务调度。
  • 分支、摘要、向量记忆、跨 Agent 历史迁移。

验收证据必须证明
进程 A 保存 → 关闭 → 进程 B 打开续接历史一致，模型收到的工具批次与 continuation 原值保留
两工作进程竞争同一个 revision只有准入成功者调用模型 / 工具；不是“执行两次再丢一次结果”

长历史选择最近完整轮次工作集缩小，归档不被裁剪；blocked 不能通过选择器绕过
越域、坏版本、变更 agentKey、删除竞态全部在执行前拒绝或由原子 CAS 仲裁；不静默创建空会话
