源码与修改说明

基于 Multica agent-transcript-dialog，固定版本 10f0ab332e57035feadae43cff2cd511f0d1d1f1。保留官方 tokens、图标节点及步骤配对、分组、时间线、详情数据与产出算法；将 React 组件转写为原生 HTML/CSS/DOM，移除后台依赖，注入合成数据，并在弹窗外增加评审控件。Inter / Geist Mono 字体来自 Fontsource 5.3.0。此预览不接收或上传真实数据。

本研究稿覆盖示例中的文本、工具、diff、长输出与常见界面状态。富媒体、语法高亮、虚拟列表、网络重连与真实流式更新属于生产接入工作；未进行原版运行截图逐像素比对。
