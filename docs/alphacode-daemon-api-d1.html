01 / 受理、执行、落盘是三件事
202 accepted→running→completed→saved
execution 表达模型与工具的状态；outcome 保留 ADK 的 completed / refused / limited 等结果；persistence 单独表达保存状态。HTTP 202 和 request.finished 都不是保存成功。新输入仅在会话 eligibility 为 ready 时准入。
02 / 幂等必须穿透到 Session
客户端为一次逻辑输入生成稳定 requestId；作用域为 workspace + session。先查该 ID，再检查 busy。同 ID 同内容返回原请求，不重发 token；不同内容返回 409 REQUEST_MISMATCH。
原始输入哈希、准备后的 Skill 输入与稳定请求 ID 需持久关联；不能在重试时重新展开已变化的 Skill。已有 SessionTurn 的输入哈希不等于完整的 HTTP 幂等回执。
03 / SSE：快照与订阅之间不丢事件
初次订阅先发 state.snapshot。恢复优先使用 Last-Event-ID，首次手动连接可用 ?after=dm_01:12；两者同时存在时 header 优先。游标按会话递增，不复用 ADK 单次 run 的 seq。
服务端在同一串行临界区绑定快照游标和后续订阅。缓冲溢出、游标超前或实例改变时，发送 stream.reset 和权威快照。客户端丢弃旧投影，不把旧 delta 叠加到新快照。
04 / 审批不是一个布尔开关
审批由 approvalId + requestId + runId + toolCallId 绑定；命令预览从服务端读取。第一个有效决定原子生效，同决定重试返回回执，反向决定返回 409 APPROVAL_CONFLICT。
取消或过期使未处理审批失效；默认有效期拟定 10 分钟，过期拒绝本次工具。界面断开不视为批准，两个客户端同时点击也只能执行一次。
05 / 崩溃恢复不等于重跑
运行中或 unsaved 状态重启后，只恢复已提交归档和 pending 标记，不伪造未保存文本、审批 Promise 或工具结果。返回 RECOVERY_REQUIRED；没有内存候选时，flush 也不能补救。
正常 unsaved 时，/persistence/flush 只补写捕获的结果，不执行模型或工具。冲突和未知副作用需要显式恢复流程，P0 不自动接管、不自动换 ID。
06 / 跨进程传输可移植的数据
协议仅传 JSON，不暴露 Agent、Provider、密钥或原始 Error。时间使用 UTC ISO 字符串；持续时间传毫秒，不跨进程相减 performance.now()。
快照保留最近 50 条消息，历史以 cursor 分页；错误统一为 { error: { code, message, traceId, retryable } }。requestId 与 traceId 分别对应逻辑执行和某次 HTTP 请求。


本地服务，也需要真实的信任边界
  • 默认只绑定 127.0.0.1；精确验证 Host、Origin，不使用通配 CORS。
  • CLI 使用受保护发现文件中的 Bearer 凭证。浏览器以短期单次 launch code 换取 HttpOnly、SameSite=Strict、host-only cookie；HTTPS 时加 Secure。
  • launch code 放 URL fragment，读取后立即清除；不得放持久 token、模型密钥或工作区秘密。
  • 浏览器写操作要求精确 Origin、JSON Content-Type 和会话绑定的 X-AlphaCode-CSRF。cookie 没有端口隔离能力；同源校验不能省。
  • 缺少 Origin 的原生客户端必须持有 Bearer；不能用缺少 Origin 绕过浏览器认证。未认证请求 401，非法 Origin / 权限 403。
  • 工作区注册和 daemon 停止只允许可信 native 管理能力；普通浏览器身份没有该能力。
  • 消息、Markdown、工具输出全部按不可信内容渲染；前端不接收服务端任意 HTML，不把浏览器请求直接映射为 Shell。
  • launch code 拟定 60 秒且原子单次消费；浏览器会话拟定 8 小时，重启失效。此处是实现要求，本页不模拟安全保证。


流控与资源预算 · 拟议默认值
SSE 每 15 秒发送注释心跳；每会话保留最多 512 条 / 2 MiB 事件，先到先淘汰。慢客户端超过 1 MiB 排队即断开，重连恢复，不阻塞 Agent。快照与单条消息受字节预算约束，必要时返回分页或有标记的截断；历史默认 50、最大 100 条。JSON 请求最大 64 KiB；超限 413，限流 429 + Retry-After。第一版同会话最多一轮执行，不做隐式队列。
同一 ALPHACODE_HOME 默认一个 daemon，配置与数据库指纹不匹配时拒绝复用。按 canonical workspace ID 和 session ID 管理实例；不能让不同客户端各自打开独立 runtime。浏览器 disconnect 只撤销订阅；daemon stop 才执行取消、排空、保存、关闭资源。保存失败进入 stop_failed，不伪报退出成功。

模块建议改动关键验收
daemon / lifecycle独立入口、启动锁、受保护发现文件、认证握手、版本与配置指纹。两个终端同时启动只得到一个实例；Windows 关闭终端后仍可连接。
runtime / send接收稳定 requestId，透传至 Session；暴露执行与保存状态。运行中与提交后重试不重跑模型 / 工具；ID 冲突返回 409。
approval broker审批 ID、运行绑定、原子决定、超时与取消失效。Web 与 TUI 同时批准只执行一次；旧审批不能授权新命令。
event hub会话级游标、原子快照订阅、有限回放缓冲与背压。断线时 Agent 继续；重连文本不丢不重；过期时快照重置。
RemoteChat / TUI保留现有 UI 合同；将客户端 detach 与 runtime close 分离。执行中 /web 只 attach；TUI 退出策略明确，不误杀共享运行。
web / shellSolid + Vite 独立 DOM 构建；同源静态资源、输入、流式消息与审批。刷新不重跑；未认证、跨 Origin、非法工作区访问被拒绝。
persistence补齐 HTTP 回执关联；复用 Session CAS 和已保存历史，不修改执行语义。完成但未保存单独可见；flush 只写存储；崩溃 pending 不自动执行。
P0：一个真实的纵向闭环
01Windows 后台生命周期验证；不安装系统服务。
02daemon + TUI 同一会话，先把执行 / 审批 / 保存跑通。
03Web 壳与 /web 打开当前会话；保留全部故障状态。
明确暂不做
公网 / 局域网访问、多用户授权、PTY、Monaco、文件树、复杂 diff、分布式锁、每会话子进程、自动接管崩溃任务。也不把 HTTP 或浏览器认证放进通用 ADK。
